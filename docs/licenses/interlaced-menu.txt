Interlaced Menu core v0.0.1 with MiSTerVision Y/C extension

MiSTerVision includes a modified build of the InterlacedMenu.rbf release by Izzie Walton:
https://github.com/iwalton3/Menu_MiSTer/releases/tag/v0.0.1

The corresponding source consists of third_party/Menu_MiSTer-source.tar.gz and fpga/interlaced/ in the accompanying MiSTerVision source bundle. The latter directory contains the scaler routing patch, added Y/C module, tests, and build script. The extension reuses Mike Simone's GPL-2.0-or-later yc_out encoder from the upstream source. Upstream copyright notices remain intact. MiSTerVision's modifications to this core remain GPL-2.0-or-later.

Build with python3 fpga/interlaced/build.py /tmp/interlaced-yc-build. The script uses a pinned Quartus 17.0.2 container. tools/interlaced-core.json pins the modified bitstream and upstream source archive by SHA-256. See fpga/interlaced/README.md for build requirements and validation.
