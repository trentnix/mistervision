# MiSTerVision v1.5.2

This maintenance release adds no new features or capabilities. It improves error reporting and diagnostics to help troubleshoot startup, performance, and display issues.

- The standard launcher automatically saves bounded startup logs and preserves the last failed launch.
- Startup errors identify the active MiSTer INI file and explain how to enable a disabled Linux framebuffer.
- Playback diagnostics distinguish source metadata, requested transcode limits, Plex processing decisions, and the video format received by MPlayer.

Startup failures are recorded in `/media/fat/mistervision/startup-error.log`. For playback or display troubleshooting, follow the [diagnostics instructions](https://github.com/trentnix/mistervision/blob/v1.5.2/docs/GO_DIAGNOSTICS.md). This release does not include a confirmed fix for the outstanding SuperStation One reports.
