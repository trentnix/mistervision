# MiSTerVision v1.7.1

- **Native analog tearing fix:** Playback now synchronizes with analog scanout when Menu uses `fb_terminal=2` at 640×240 or 640×288. The SuperStation One composite reporter confirmed smooth, tear-free playback with the test build. Selection is automatic and requires no replacement Menu core. HDMI, scaler output, and interlaced output keep their existing synchronization.
- **Saved MiSTer controller mappings:** MiSTerVision now uses mappings saved through MiSTer’s Define joystick buttons, including menu confirm/back assignments. Explicit MiSTerVision input profiles still take precedence. Missing or unusable maps use the built-in controls.
- **Documentation and branding:** Updated PAL RGB and component setup guidance, recorded contributor validation of RGB 576i, and refreshed the logo to represent both Jellyfin and Plex.

Validation covers automated playback, browser, input, rendering, and update checks, plus MiSTer playback through native analog, progressive scaler, HDMI, and interlaced output. Device checks include pause/resume, seeking, picture changes, overlays, and return to Menu.

Update through About or your existing Downloader registration. Manual installations use `mistervision-v1.7.1-progressive.zip`. The single package supports CRT and HDMI, including interlaced output, and preserves settings and sign-in.
