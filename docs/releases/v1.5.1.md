# MiSTerVision v1.5.1

- Fix startup and return to the menu when launching from ConsoleMode. CRT and HDMI use the same display settings as standard MiSTer launches.
- Support the active MiSTer INI profile, including alternate profiles, with separate configuration backups.
- Improve startup diagnostics for display settings and ConsoleMode failures.

Tested on a MiSTer Multisystem 2 with ConsoleMode 1.1.4.2 and the standard MiSTer menu, covering progressive CRT, interlaced CRT, and HDMI output. SuperStation One confirmation is still welcome.

Update through About or your existing Downloader/update_all installation when its database offers this version. Existing settings and sign-in are preserved. ConsoleMode CRT output requires a working framebuffer configuration. See [Display setup](https://github.com/trentnix/mistervision#display-setup).
