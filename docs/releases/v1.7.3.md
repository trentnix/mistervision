MiSTerVision v1.7.3 improves analog display compatibility and startup with alternative MiSTer frontends.

- Adds experimental interlaced S-Video and composite output to the bundled core, with corrected PAL color calculations and picture-edge timing.
- Fixes progressive startup when Zaparoo is the active MiSTer host.
- Preserves native analog framebuffer settings when launching through ConsoleMode.
- Updates the Go runtime to 1.27.3.

The combined build passed automated application and FPGA tests. Local MiSTer checks covered 240p and 480i startup, H.264 playback, and return to Menu. The maintainer also confirmed normal use on a component CRT. Direct S-Video/composite hardware confirmation is still requested in [issue #54](https://github.com/trentnix/mistervision/issues/54).

Update through About, your registered Downloader database, or the attached application ZIP. Existing settings are preserved. Start with a working progressive picture before enabling interlacing, and keep your adapter's working INI settings. See the [display guide](https://github.com/trentnix/mistervision/blob/v1.7.3/docs/GO_DISPLAY.md#experimental-interlaced-s-video-and-composite).

Thanks to @matijaerceg for the encoder fixes and regression tests.
