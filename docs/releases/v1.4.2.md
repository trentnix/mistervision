# MiSTerVision v1.4.2

## Release summary

MiSTerVision now recognizes its Downloader database registration. Registered installations keep update checks and release notes in About, but use `update_all` or Downloader to install updates. This prevents the two updaters from replacing each other’s installed version.

Register the database once using the INI file provided by theypsilon’s MultiDatabases project. Installation instructions are in the README at github.com/trentnix/mistervision. Exit MiSTerVision before running an external updater.

Manual installations continue to use the built-in updater. If Downloader configuration cannot be read, About explains the problem and disables installation until it is resolved. Removing the registration and restarting restores built-in updates.

## Installation

Users on v1.4.1 can install this release through About. Users with the database registered should run `update_all` or Downloader once its database lists v1.4.2.

Users on v1.4.0 or earlier must install through Downloader or copy the release files manually once. Keep existing settings and state. Both progressive and interlaced packages include the interlaced core and preserve the display mode of existing installations.
