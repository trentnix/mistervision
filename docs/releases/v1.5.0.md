# MiSTerVision v1.5.0

## HDMI support and clearer CRT text

MiSTerVision now supports HDMI displays alongside its CRT output. Automatic aspect handling fits video to the screen, and widescreen carousel backgrounds fill the display while text and controls keep their familiar layout.

- Bound framebuffer resolution independently of HDMI output timing. The default uses a 640×360 framebuffer for 720p and 1080p output, with hardware scaling to the display.
- Draw browsing text and artwork at the available viewport resolution. Larger framebuffer limits are configurable.
- Improve CRT readability with brighter secondary text, bold loading and seeking labels, and larger bold preview titles and text.
- Improve the picture, subtitle, and audio selection menus at smaller playback resolutions.
- Simplify installation to one package for progressive and interlaced output, with the interlaced core included.
- Reorganize display setup, updating, and troubleshooting instructions in the README.

## Installation and updating

The application ZIP retains the `-progressive.zip` filename for existing updaters and Downloader. It supports CRT, HDMI, and configurable interlaced output. Existing settings and sign-in are preserved. No separate interlaced package is needed.

Users on v1.4.1 or later can update through About. If the MiSTerVision database is registered, exit the app and run `update_all` or Downloader once its database lists v1.5.0. Users on v1.4.0 or earlier must install through Downloader or copy the release files manually once.

For HDMI, keep application interlacing off and start with automatic aspect and default framebuffer limits. For CRT output, keep the timing appropriate to your television and adapter. See the README’s Display setup section for configuration examples.

## How this release was tested

Testing used a MiSTer Multisystem 2, a consumer 4:3 CRT, and an HDMI monitor. Checks covered 240p and 480i CRT output, including composite video playback, and 720p and 1080p HDMI output. Browsing, preview text, video playback, Live TV, seeking, and playback controls were checked while choosing the defaults.

Automated checks cover rendering, display geometry, decoder behavior, startup recovery, and concurrency. Release verification checks the actual archives, executable metadata, checksums, and updater installation and recovery. The packaged client and player also run an isolated smoke test on MiSTer.
