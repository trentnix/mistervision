# MiSTerVision v1.7.2

- **More readable carousel names:** Library names now wrap into two centered lines without shrinking the font. Wider labels show more of each name. Names that do not fit end in an ellipsis, and the item count stays below the title area.

Also included since v1.7.0:

- **Native analog tearing fix:** Playback synchronizes with analog scanout when Menu uses `fb_terminal=2` at 640×240 or 640×288. A SuperStation One composite user confirmed smooth, tear-free playback. Selection is automatic and requires no replacement Menu core.
- **Saved MiSTer controller mappings:** MiSTerVision uses mappings saved through Define joystick buttons, including confirm/back assignments. Explicit MiSTerVision input profiles take precedence. Missing or unusable maps use the built-in controls.
- **Documentation and branding:** Updated PAL RGB and component guidance, recorded contributor validation of RGB 576i, and refreshed the logo to represent Jellyfin and Plex.

The carousel was checked on MiSTer and through 4:3 and widescreen rendering tests, including long names and wide Unicode characters. Automated checks cover browsing, playback, input, rendering, and updates. The analog fix was tested through native analog, progressive scaler, HDMI, and interlaced output.

Update through About or your existing Downloader registration. Manual installations use `mistervision-v1.7.2-progressive.zip`. The single package supports CRT and HDMI, including interlaced output, and preserves settings and sign-in.
