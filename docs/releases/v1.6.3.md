# MiSTerVision v1.6.3

## Playback controls

- Left/Right seeks backward or forward: 30 seconds for movies and shows, 10 seconds for music.
- LB/RB changes music tracks or moves between queued videos.
- Up/Down shows or hides playback controls.

Automatic trigger-axis bindings have been removed. This fixes unintended seeking on controllers whose right-stick axes were mistaken for triggers. Triggers are no longer part of the default playback layout. Explicit input profiles can still assign triggers to seeking or other actions. Live TV remains non-seekable.

On-screen instructions and controller documentation reflect the new layout. Automated input, playback, and rendering checks passed, and the controls were tested on MiSTer.

## Updating

Update through About or your existing Downloader registration. Manual installations use `mistervision-v1.6.3-progressive.zip`, which supports progressive and interlaced output. Existing settings and sign-in are preserved.

If you added the axes 2/5 workaround from issue #30, remove those seek bindings to use the new defaults. Explicit configuration overrides are preserved by the update.
