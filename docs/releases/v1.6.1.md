# MiSTerVision v1.6.1

## Release summary

- Fixed video tearing in progressive output, including HDMI and 240p CRT playback. Frames are prepared separately from the displayed frame and presented through page flipping.
- Fixed missing or incomplete Plex artist album lists. Compilations, EPs, and other releases now appear alongside studio albums. Jellyfin browsing is unchanged.

Validated with automated playback, rendering, and browsing checks, plus on-device testing. A SuperStation One reporter confirmed the tearing improvement. Remaining stutter on that setup is still under investigation.

## Installation

Update through About or your existing Downloader registration. Manual installations use `mistervision-v1.6.1-progressive.zip`, which supports both progressive and interlaced output. Install the matching client and player together. Existing settings and sign-in are preserved.
