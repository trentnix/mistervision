# MiSTerVision v1.7.0

## Playback and library controls

- **Next episode:** When an episode ends, choose Play next episode or Back to episodes. The preview includes episode artwork and follows episode order across seasons. It works with Plex and Jellyfin, including playback started from Continue Watching. Nothing starts automatically.
- **Skip intros and other segments:** Press X on the default controller mapping or O on the keyboard when a skip prompt appears. Supported segments include intros, credits, recaps, previews, and commercials when supplied by the server. The prompt disappears after eight seconds. Up/Down brings it back while the segment is still active.
- **Watched status:** Mark movies and episodes watched or unwatched directly from their preview with X/O. Lists show a green Watched label alongside the duration.
- **Music options:** Select/Tab opens repeat and shuffle for the current album or playlist. X/O changes the music background.
- **Held controls:** Hold Left/Right to keep seeking. Hold Start for two seconds to open exit confirmation from any screen.
- Loading, buffering, and seeking overlays now have subtly rounded corners.

Segment availability depends on server metadata. Plex needs analyzed markers. Jellyfin needs a segment provider and a completed media-segment scan. Existing input profiles continue to control bindings and labels.

## Validation and maintenance

The project now builds with Go 1.27.2 and updated analysis tools. Automated checks cover both providers, playback transitions, input, rendering, and update packaging. The controls and next-episode flow were also tested on MiSTer, including Plex episode playback.

## Updating

Update through About or your existing Downloader registration. Manual installations use `mistervision-v1.7.0-progressive.zip`. The single package supports CRT and HDMI, including interlaced output, and preserves settings and sign-in.

If you are upgrading from v1.4.0 or earlier, use Downloader or install the ZIP manually once.
