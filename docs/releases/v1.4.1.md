# MiSTerVision v1.4.1

## Release summary

This update requires one manual installation if you are running v1.4.0 or earlier. Download an installation ZIP from github.com/trentnix/mistervision/releases and copy its files onto the SD card with MiSTerVision closed. Keep your settings and state folders. Later updates work through About again.

Both installation packages now include the interlaced core. New users can choose progressive or interlaced output without editing configuration. Existing users keep their connections, sign-in, preferences, and display mode.

## Installation

Choose `mistervision-v1.4.1-progressive.zip` for the progressive default or `mistervision-v1.4.1-interlaced.zip` for an interlaced first installation. Both contain the same application, player, and core. Extract the ZIP, copy `Scripts/MiSTerVision.sh` into `/media/fat/Scripts/`, and copy the contents of `mistervision/` into `/media/fat/mistervision/`. Reopen MiSTerVision.

The presets apply only when no current or legacy configuration exists. Copying either ZIP over an existing installation preserves its display mode. To change that mode, edit `display.interlaced` in `settings.json` while the application is closed. Neither archive contains active configuration, credentials, or saved state.

Older clients display “No installation bundle is available” on the release page and do not offer Install. This is expected for this transition. No incompatible download is attempted.

Progressive NTSC output is normally 240p. Interlaced NTSC output is 480i. PAL validation and SuperStation One Console Mode compatibility remain unverified. Bundling the core does not establish support for those configurations.
