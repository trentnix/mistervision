# MiSTerVision v1.5.3

Fixes startup with interlaced CRT output over YPbPr component. Affected setups could remain on the InterlacedMenu screen and then return to the MiSTer menu without opening MiSTerVision.

MiSTerVision now configures the full-height framebuffer required by its interlaced core. The correction applies automatically at startup and preserves existing color, sync, and other core settings.

Validation includes the automated regression suite and on-device interlaced and progressive startup checks on a MiSTer Multisystem 2 connected through component video.
