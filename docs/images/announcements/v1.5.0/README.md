# MiSTerVision v1.5.0 announcement images

These screenshots use the released application’s production renderer and real Jellyfin library data. They capture the default 640×360 HDMI framebuffer and use exact 3× nearest-neighbor scaling to produce 1920×1080 PNGs. No simulated scanlines, composited artwork, or other visual effects were added. The carousel background fills the screen. Other browsing screens keep their centered 4:3 layout.

Start with the carousel to show widescreen support and the episode preview to show the larger, bolder text.
