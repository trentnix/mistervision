MiSTerVision

Start here

Use the single application package for a first installation. It keeps MiSTer's current display mode and includes the core needed for optional interlaced output. Start with working display settings and the default framebuffer limits. You do not need a connection file for local server discovery.

Install through update_all or Downloader

1. Download the database registration ZIP from https://github.com/theypsilon/MultiDatabases_MiSTer/tree/main/mister-vision.
2. Extract downloader_MultiDatabases_mister-vision.ini to /media/fat. Do not replace downloader.ini.
3. Exit MiSTerVision if it is running, then run update_all or MiSTer Downloader.

The database installs the application package and preserves existing settings and sign-in. Use the same updater for later releases. About shows release information and directs registered installations to the external updater. To return to built-in updates, remove the registration and restart.

Manual installation

1. Download the application ZIP and extract it on your computer.
2. If MiSTerVision is running, exit it. Keep a backup before upgrading.
3. Copy Scripts/MiSTerVision.sh to /media/fat/Scripts/ and the contents of mistervision/ to /media/fat/mistervision/. Copy the application and matching MPlayer together. Keep the launcher filename free of spaces.
4. Preserve existing configuration and state. The archive contains examples but no active settings, credentials, saved state, or caches. Make the launcher and binaries executable if your filesystem requires it.

Check your display

MiSTerVision uses the Linux framebuffer. It does not provide independent CRT and HDMI pictures. Choose one output setup before launching.

- Analog CRT: retain CRT-compatible timing. MiSTerVision needs the Linux framebuffer on the analog scaler. Adapter-specific timing and sync settings matter.
- HDMI monitor: keep display.interlaced false and display.aspect_ratio on auto. Keep the default framebuffer limits. The hardware scaler enlarges the smaller framebuffer to the HDMI signal resolution.
- Optional 480i: first verify browsing and playback on a compatible CRT route, then set display.interlaced true. The included InterlacedMenu.rbf loads automatically. Do not use this mode for an ordinary HDMI monitor.

The single application ZIP retains the -progressive.zip filename for compatibility with existing updaters and Downloader. It includes the optional interlaced core. First launch creates settings.json only when no current or legacy configuration exists. Reinstalling does not change an existing display configuration. Enable interlacing through display.interlaced in settings.json.

See tested adapter settings, output limits, and recovery in docs/GO_DISPLAY.md in the source bundle or https://github.com/trentnix/mistervision/blob/main/docs/GO_DISPLAY.md.

Connect and play

Launch MiSTerVision from Scripts. For Jellyfin, select a discovered server and approve its Quick Connect code in a signed-in client. For Plex, open About, choose Connections, then Plex. Approve the code at https://plex.tv/link, choose a viewer if offered, and select a server.

For a fixed or remote address, add server.provider and server.url to settings.json, preserving other settings. Use settings.example.json as a reference. The configuration guide covers saved connections and legacy settings: https://github.com/trentnix/mistervision/blob/main/docs/GO_CONFIGURATION.md.

Updates and older installations

Manual installations use About -> View release -> Install. The standard launcher restarts the app after successful installation. Custom launchers without restart support require reopening it. Updates preserve settings and state. Interrupted replacements recover at startup. Keep .update-pending if recovery is needed.

First installation and upgrades from v1.4.0 or earlier require Downloader or a manual file copy. Older About installers cannot install these renamed archives. When moving from MiSTerFin CRT, back up the old directory and follow https://github.com/trentnix/mistervision/blob/main/docs/GO_BUILD.md#moving-from-misterfin-crt before installing. Do not copy old binaries over the new pair.

Checksums and source

The release's SHA256SUMS checks the ZIP and source archive. On Linux, run sha256sum -c SHA256SUMS in the directory containing those downloads. The ZIP also contains checksums for its extracted files.

VERSION identifies the release. BUILD.txt records its revision, compiler metadata, and executable checksums. The source archive includes the project, MPlayer's upstream source, patches, build recipes, and the exact interlaced Menu source archive. Its third_party/Menu_MiSTer-source.tar.gz contains the complete upstream Quartus project. To rebuild MPlayer, extract the source bundle and run make native-player from its project directory. Docker still needs its pinned base image and compiler packages.
